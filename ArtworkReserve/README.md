# Story 备用背景

用浏览器打开同目录的 `index.html`，可以浏览八张原画、观看动效、暂停，以及预览单张图在竖屏和帐篷横屏中的裁切。整个文件夹可以离线使用。

八份 SVG 各自包含图形、纸纹和动画。每张都是 600 × 600 的矢量画布。直接使用文件名显示静帧，文件名后加 `#ambient` 播放动效。遵循 Story 播放器的约定，开启系统「减弱动态效果」时加载无片段的静帧。

有对应的新录音后，将选中的 SVG 复制到 `Resources/Artwork/<录音 ID>.svg`，再在 `Resources/recordings.json` 登记录音及其波形。备用素材位于应用资源目录之外。
